# **Strings in Rust – Complete Notes**

Strings are used to store text.

You can use the `&str` type to create a string:

```rust
let greeting: &str = "Hello";
println!("{}", greeting);
```

**Note:** Strings are surrounded by double quotes (`"Hello"`).

There are **two main types** of strings in Rust:

- `&str` — called “string slices”. Used for fixed text like `"Hello"`.
- `String` — used when you need a string that can change.

In this chapter you will mostly work with the `String` type because it is more flexible and can be changed over time.

---

### Create a String

You can create a `String` from a string literal using the `to_string()` method or the `String::from()` function:

```rust
let text1 = "Hello World".to_string();
```

```rust
let text2 = String::from("Hello World");
```

Both ways are very common in Rust — choose whichever you prefer.

---

### Change a String

Strings are mutable, so you can change them if they are declared with `mut`.

Use `push_str()` to add text to a string:

```rust
let mut greeting = String::from("Hello");
greeting.push_str(" World");
println!("{}", greeting); // Hello World
```

Use `push()` to add one character:

```rust
let mut word = String::from("Hi");
word.push('!');
println!("{}", word); // Hi!
```

---

### Concatenate Strings

You can combine strings using the `format!` macro:

```rust
let s1 = String::from("Hello");
let s2 = String::from("World!");
let s3 = String::from("What a beautiful day!");

let result = format!("{} {} {}", s1, s2, s3);
println!("{}", result);
```

You can also use the `+` operator to combine strings, but it can get messy with many values:

```rust
let s1 = String::from("Hello");
let s2 = String::from("World!");
let s3 = String::from("What a beautiful day!");

let result = s1 + " " + &s2 + " " + &s3;
println!("{}", result);
```

**Important note from the page:**  
You can only add a `&str` to a `String` with `+`.  
That is why `&s2` and `&s3` are used here.

`format!` is often the preferred choice over using `+` for combining strings.

---

### String Length

You can use the `.len()` method to get the length of a string:

```rust
let name = String::from("John");
println!("Length: {}", name.len()); // 4
```

---

### Why does `&s2` turn a `String` into `&str`?

This is the key point the page mentions.

In Rust:

- `String` is an **owned**, growable string (it owns its data on the heap).
- `&str` is a **string slice** — a view (a reference) into some string data.

When you write `&s2`:

- You are **not** converting the whole `String` into a new type permanently.
- You are creating a **reference** (`&`) to the existing `String`.
- Rust automatically treats a reference to a `String` (`&String`) as a string slice (`&str`).

This is possible because of a feature called **Deref coercion**.  
A `&String` can be automatically “dereferenced” into a `&str`.

So in this line:

```rust
let result = s1 + " " + &s2 + " " + &s3;
```

- `s1` stays a `String` (the left side of `+` must be a `String`).
- `" "` is already a `&str` (a string literal).
- `&s2` and `&s3` turn the `String`s into `&str` so they can be added.

You **cannot** do this:

```rust
s1 + s2   // Error! You cannot add two String values directly
```

You **must** add a `String` + `&str`.
