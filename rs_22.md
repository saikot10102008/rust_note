# **Arrays in Rust – Complete Notes**

Arrays are used to store multiple values in a single variable, instead of declaring separate variables for each value.

---

### Create an Array

You can create an array using square brackets `[ ]`, and separate the values with commas.

**Note:** All values must be of the same data type.

```rust
let numbers = [1, 2, 3, 4, 5];
```

This creates an array with five integers.

---

### Access Array Elements

To access an array element, refer to its index number.

Array indexes start with 0:  
`[0]` is the first element, `[1]` is the second element, etc.

```rust
let numbers = [1, 2, 3, 4, 5];
println!("The first number is: {}", numbers[0]);
```

---

### Change Array Values

To change the value of a specified element, refer to the index number and assign a new value.

Remember to make the array mutable (using the `mut` keyword):

```rust
let mut numbers = [1, 2, 3, 4, 5];
numbers[0] = 10;
println!("The new first number is: {}", numbers[0]);
```

---

### Array Length

You can get the number of elements in an array using the `.len()` method:

```rust
let numbers = [1, 2, 3, 4, 5];
println!("This array has {} elements.", numbers.len());
```

---

### Loop Through an Array

You can loop through the array elements with the `for` loop:

```rust
let fruits = ["apple", "banana", "orange"];

for fruit in fruits {
  println!("I like {}.", fruit);
}
```

---

### Print the Entire Array

When printing the **whole** array, you must use `{:?}`:

```rust
let numbers = [1, 2, 3, 4, 5];
println!("{:?}", numbers);
```

If you are just printing **one element** from the array, you can use `{}`:

```rust
let numbers = [1, 2, 3, 4, 5];
println!("{}", numbers[0]);
```

**Summary rule:**

- Use `{}` when printing a single element (basic types like strings, numbers, booleans).
- Use `{:?}` when printing the entire array (or other data structures).

---

### Fixed Size (Arrays) vs Dynamic Size (Vectors)

Arrays in Rust have a **fixed size**. You cannot add or remove elements after the array is created:

```rust
// An array with 3 elements
let mut cars = ["Volvo", "BMW", "Ford"];

// Trying to add another element will result in an error
cars[3] = "Mazda";  // Error: index out of bounds
```

For operations that require adding and removing elements, use **Vectors**, which are resizable arrays.

The size of a vector is dynamic — it can grow and shrink as needed.

You can use the `vec!` macro to create a vector:

```rust
// A vector with 3 elements
let mut cars = vec!["Volvo", "BMW", "Ford"];

// Add another element
cars.push("Mazda");

println!("{:?}", cars); // ["Volvo", "BMW", "Ford", "Mazda"]
```
